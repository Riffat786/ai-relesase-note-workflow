# Project Charter

## Project Title

AI-Assisted Release Notes Workflow

---

## Problem Statement

Release information is often distributed across multiple systems such as Jira and technical implementation notes. Manually consolidating this information to prepare customer-facing release notes is time-consuming and error-prone.

---

## Project Objective

Develop an AI-assisted workflow that automates the extraction, consolidation, generation, and review of release notes.

---

## Scope

### In Scope

- Extract release information from Jira.
- Read implementation notes.
- Consolidate release data.
- Generate customer-facing release notes.
- Review release notes for publication readiness.

### Out of Scope

- Automatic publishing of release notes.
- Modification of Jira issues.
- Editing implementation notes.

---

## Deliverables

- Release Data Extractor
- Release Note Generator
- Release Note Reviewer
- Consolidated Release Dataset
- Customer-facing Release Notes
- Review Report

---

## Success Criteria

- End-to-end workflow successfully demonstrated.
- Release notes generated from consolidated release data.
- Review completed before publication.
