# Generate Release Notes

## Purpose

Generate customer-facing release notes from the consolidated release dataset.

## Input

Consolidated Release Dataset:

$ARGUMENTS

## Instructions

Use the **Release Note Generator** skill to:

1. Read the consolidated release dataset specified in `$ARGUMENTS`.
2. Generate professional customer-facing release notes.
3. Organize the content into appropriate sections such as:
   - Release Overview
   - New Features
   - Enhancements
   - Bug Fixes
   - Regulatory Updates
   - Known Issues (if applicable)
4. Ensure the content is business-focused, concise, and publication-ready.

## Output

Generate:

- `sample-data/release-notes.md`
