## Future AI-Assisted Workflow

Various phases in the release notes creation process are automated.

---
# Workflow Overview

```text
       
Collect information from JIRA (Release Notes Creator skill) 
        ↓
Draft the release notes (Release Notes Creator skill)
        ↓
Do the self-review (Release Notes Reviewer Skill) 
        ↓
Get it reviewed from stakeholders (Human)
        ↓
Create the second draft (Human)
        ↓
Publish the Release Notes (via the Documentation Publishing skill)
```

----

| Component Type | Purpose                |
| -------------- | -----------------------|
| Skill          | Release Notes Creator  |
| Skill          | Release Notes Reviewer |
