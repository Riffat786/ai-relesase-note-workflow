# Current Release Notes Workflow

Currently, writers create release notes manually. They collect all the inputs from various stakeholders and go through the entire lifecycle. 

---

# Current Workflow

```text
Collect info about items for the release items from JIRA and other systems
        ↓
Create the first draft  
        ↓
Do self-review
        ↓
Get it reviewed from all the stakeholders
        ↓
Create the second draft
        ↓
Send for approval
        ↓
Publish the Release Notes
```
