# Release Notes — Version 14.1

## Overview

Release 14.1 focuses on faster customer onboarding, more reliable transaction processing, and continued regulatory compliance. This update introduces bulk customer onboarding, strengthens safeguards against duplicate transactions, and refreshes regulatory reporting to align with the latest standards. Together, these changes help teams work more efficiently while maintaining accuracy and compliance.

---

## New Features

### Bulk Customer Import
You can now onboard multiple customers at once by uploading a CSV file, removing the need to enter records one at a time. The import validates your data as it is processed and flags potential duplicates, helping ensure clean, accurate customer records. Progress is tracked throughout the upload so you always know the status of your import. This significantly reduces manual effort and shortens onboarding time.

---

## Enhancements

### Improved Duplicate Transaction Protection
Transaction processing now includes stronger safeguards to prevent the same transaction from being submitted more than once. If a potential duplicate is detected, a clear, user-friendly message is shown before the transaction proceeds. This improvement increases processing accuracy and helps protect against unintended duplicate payments.

---

## Regulatory Updates

### Updated Regulatory Reporting
Regulatory report templates have been updated to comply with the latest reporting standards, including new compliance fields required for accurate submissions. Report generation and export have also been made faster, helping teams meet compliance requirements with greater confidence and efficiency.
