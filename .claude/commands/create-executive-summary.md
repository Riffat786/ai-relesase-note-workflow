# Create Executive Summary

You are assisting with generating a concise executive-level summary of release content.

Load and follow the **Documentation Style Guide** skill.

Create a high-level summary suitable for management, stakeholders, and executives.

## Focus Areas

- Major features and their business value
- Customer impact and benefits
- Risks and considerations
- Key highlights and strategic importance

## Avoid

- Technical implementation details
- Detailed issue lists or changelog-style content
- Internal or non-customer-facing work

## Output Structure

```
# Executive Summary

## Key Highlights

## Customer Benefits

## Risks and Considerations

## Recommendation
```

Generate each section. The "Recommendation" section should briefly state whether the release is ready for publication, has deployment considerations, or requires additional review.

This summary is intended for stakeholder review and communication. It complements (not replaces) the detailed release notes.
