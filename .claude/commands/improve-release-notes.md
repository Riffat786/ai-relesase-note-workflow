# Improve Release Notes

You are assisting with improving release note content based on quality review findings.

Load and follow the **Documentation Style Guide** skill and the **Release Note Specialist** skill.

Apply reviewer recommendations to the provided draft release notes in `$ARGUMENTS` while preserving factual accuracy and customer focus.

## Requirements

- Do not invent information beyond what is in the source material or what is explicitly recommended by the review.
- Preserve original meaning and factual accuracy.
- Maintain customer focus.
- Improve clarity and consistency where possible.
- If a review recommendation would require inventing details not in the source, preserve the gap instead of fabricating content.

## Output

Provide the improved release notes.

Include a summary of changes made and any recommendations that could not be applied (with explanation of why, e.g., "insufficient source information").

This improved draft is intended for human review and approval before publication.
