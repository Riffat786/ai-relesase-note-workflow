🐛 Bug Fixes

Bug ID Description Fix / Solution
#5 Category and total budget values above ₹1,00,000 displayed with incorrect rounding, causing discrepancies between dashboard totals and transaction sums. Budget totals now match the exact sum of transactions to the rupee across all value ranges.
#6 Some users received two identical bill reminder notifications for the same recurring bill. Duplicate notifications have been eliminated; you now receive exactly one reminder per scheduled bill.
#7 When navigating back from Onboarding Step 4 to Step 3, slider values reset to defaults instead of retaining user input. Slider state now persists across forward and back navigation, retaining your inputs when you return to previous steps.

Known Issues

  • Delayed sync for linked brokerage holdings: Holdings synced from certain third-party brokerage connections (e.g., Zerodha) may experience a two to four hour sync delay before appearing in your portfolio. New holdings may not appear immediately after linking a brokerage account.
